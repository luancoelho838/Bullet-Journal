📔 Bullet Journal em C#

Aplicação de Bullet Journal em console, desenvolvida em C# com .NET 10.0, como projeto prático para estudar e aplicar conceitos de programação.

✨ Funcionalidades
📅 Exibição da data atual
🎯 Cadastro e edição de metas mensais
✅ Cadastro de tarefas diárias
😴 Cálculo de horas de sono
📝 Registro de como foi o dia
📊 Geração de resumo diário
🔎 Validação de entradas com TryParse


🛠️ Tecnologias
C#
.NET 10.0
Visual Studio


📚 Conceitos praticados

Métodos e parâmetros
List<T>
Estruturas de repetição e condição
TryParse
DateTime e TimeSpan
Retorno e passagem de dados
Manipulação de dados armazenados
